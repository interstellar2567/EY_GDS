============================================================
EY GDS SERVERLESS SECURITY
COMMAND REFERENCE
============================================================


1. PROJECT SETUP
============================================================

Create virtual environment:

python -m venv .venv


Activate virtual environment - Windows:

.venv\Scripts\activate


Install dependencies:

pip install -r requirements.txt


Upgrade pip:

python -m pip install --upgrade pip



2. RUN THE TESTS
============================================================

Run all tests:

python -m pytest


Run a specific test file:

python -m pytest tests/test_attack_detection.py

python -m pytest tests/test_dependency_scanner.py

python -m pytest tests/test_iam_scanner.py

python -m pytest tests/test_config_scanner.py

python -m pytest tests/test_security_engine.py


Run tests with more detailed output:

python -m pytest -v



3. RUN THE SECURITY DASHBOARD
============================================================

Start the Streamlit dashboard:

streamlit run dashboard/app.py


Alternative:

python -m streamlit run dashboard/app.py



4. GIT - CHECK PROJECT STATUS
============================================================

Check current Git status:

git status


Show modified files:

git diff


Show commit history:

git log --oneline


Check remote repository:

git remote -v



5. GIT - SAVE CHANGES
============================================================

Stage a specific file:

git add <filename>


Stage all changes:

git add .


Create a commit:

git commit -m "Describe the change"


Push changes to GitHub:

git push origin main


Pull the latest changes:

git pull origin main



6. GIT - BEFORE PUSHING
============================================================

Recommended workflow:

git status

python -m pytest

git add .

git commit -m "Describe the change"

git push origin main


Always make sure the tests pass before pushing.
